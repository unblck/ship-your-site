## Let your AI agent walk you through it

This extension installs the **ship-your-site** agent skill. In an editor whose chat supports extension-contributed skills (for example GitHub Copilot Chat in VS Code 1.109+), open chat in **Agent** mode and ask:

- "Help me put this site online with my own domain."
- "I bought a domain, how do I connect it to Netlify?"
- "My site works for me but my friend sees a login page."

You can also type `/ship-your-site` to start it directly.

The agent goes one step at a time and **asks before any purchase or account action**: buying a domain, signing up, production deploys, visibility or DNS changes. It never needs your passwords, card details or tokens.

Using Cursor, Claude Code, Codex or another agent? Install the same skill with:

```bash
npx skills add unblck/ship-your-site
```

Prefer to do it by hand? Follow the steps in this walkthrough; each one is a section of the full guide.
